How a snapshot is made

pure Python · standard library + watchdog
  1. Watchwatchdog sees a save
  2. Debouncewaits for edits to settle
  3. HashSHA-256 of the content
  4. Dedupeskips if unchanged
  5. Storeatomic copy + SQLite row
  6. Pruneretention keeps it lean
